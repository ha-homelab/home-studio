# Home Studio documentation wiki

This is the maintained, repository-local wiki. The pages below travel with the
source download and can be reviewed together with code changes. They are not a
claim that a separate GitHub Wiki has been published.

- [Start drawing and install](Getting-started.md): choose the editor, local
  preview, or Home Assistant route.
- [Use Dry run](Dry-run.md): try device buttons while showing real readings.
- [Troubleshoot a display](Troubleshooting.md): connection, storage, language,
  controls, and safe evidence collection.
- [Languages](Languages.md): supported locales, translated scope, and how to
  report a translation issue.
- [Development and validation](Development.md): source map, review boundaries,
  and regression commands.
- [Illustrated process and results](../process-and-results.md): delivery steps,
  behavior changes, recorded evidence and its limits.

The [main README](../../README.md) is the product overview. Detailed references
cover [architecture](../architecture.md), [Dry run](../dry-run.md),
[translation contributions](../i18n.md), and [releases](../../RELEASING.md).
Examples here use fictional project paths and contain no household data.
