# Languages

The editor and everyday installed-viewer controls support 24 languages:
English, Arabic, Bengali, Czech, German, Spanish, Persian, French, Hebrew, Hindi,
Indonesian, Italian, Japanese, Korean, Dutch, Polish, Portuguese, Russian, Thai,
Turkish, Ukrainian, Vietnamese, Simplified Chinese, and Traditional Chinese.

[Open a README in your language](../translations/README.md). Each quick start
starts with installation, drawing, and publication inside Home Assistant, then
covers the optional portable workflow and guarded device controls.
Detailed engineering guides and SVG diagrams are maintained in English.

The installed plan follows the Home Assistant profile language until a language
is selected in the plan. The host remembers that selection for this browser and
origin when storage is available. Editor and installed-plan preferences are
separate. Arabic, Hebrew, and Persian use right-to-left interface text; model
coordinates, code, geometry, and the view's physical orientation stay unchanged.

A translated interface does not translate a home's room names, entity IDs,
imported descriptions, or raw upstream errors. Changing language must not alter
the project, save a layout, or operate a device. Translation files are bundled;
there is no online translation service.

See [the i18n contribution guide](../i18n.md) for source files, coverage,
placeholders, storage behavior, and tests. Automated key checks cannot certify
idiomatic wording: report the language, screen, current text, and suggested
correction using a fictional example.
