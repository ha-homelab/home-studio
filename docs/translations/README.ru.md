## Начните в Home Assistant

Для нового дома используйте Home Studio внутри Home Assistant. Отдельная установка Python, YAML и токен доступа не нужны.

Для существующего сгенерированного или изменённого компонента сначала прочитайте раздел **Existing generated homes** в подробном руководстве: автоматического преобразования нет.

1. Установите Home Assistant 2026.10 или новее и сделайте резервную копию.
2. В HACS добавьте `https://github.com/ha-homelab/home-studio` как пользовательский репозиторий категории **Integration**. Установите стабильный выпуск Home Studio с файлом **home_floorplan.zip** и перезапустите Home Assistant.
3. Откройте **Settings → Devices & services → Add integration → Home Studio**.
4. Войдите как администратор и откройте **Home Studio** в боковой панели. Нарисуйте комнату и привяжите предметы к реальным устройствам HA.
5. Нажмите **Save draft**, затем **Publish family view**. Откройте **3D Home** и проверьте привязки в **Dry run** перед управлением устройствами.

[Home Assistant guide — English](../home-assistant-editor.md) · [Install — English](https://ha-homelab.github.io/home-studio/install.html#native-studio)

## Дополнительно: рисование, пока вы настраиваете HA

Отдельный браузерный редактор можно использовать, пока HA ещё не готов. Он не имеет живого подключения к HA. Экспортируйте JSON, затем откройте его через **Open JSON** в Home Studio внутри HA, проверьте устройства, сохраните и опубликуйте.

[Browser editor](https://ha-homelab.github.io/home-studio/planner/?lang=ru)

Нарисуйте свой дом в браузере. Учётная запись не нужна. Язык можно выбрать в верхней части редактора.

1. Добавьте комнаты, стены, двери и окна. В библиотеке 211 модель. Выберите цветовую палитру, а для подходящих предметов — рисунок поверхности.
2. Экспортируйте JSON, чтобы сохранить редактируемую копию. Черновик хранится только в этом браузере. Смена языка не изменяет ваш план.

### Дополнительно: переносимый набор и компилятор Python

Этот путь нужен только для отдельной сборки и прежних сгенерированных установок; для новой встроенной установки пропустите его.

Скачайте и распакуйте полный набор инструментов. Установите Python 3.10 или новее. В папке набора выполните:

[ZIP](https://github.com/ha-homelab/home-studio/releases/latest)

```sh
python3 scripts/build-planner-project.py --project /path/to/project.json --output dist/my-home --ha-package
```

Следуйте инструкции по установке на английском: в ней описаны резервные копии, Home Assistant OS, путь к конфигурации и перезапуск. Сам браузерный редактор не подключается к Home Assistant и не управляет устройствами.

[Home Assistant](https://ha-homelab.github.io/home-studio/install.html?lang=ru) · [README](../../README.md) · [i18n](../i18n.md)

План дома и идентификаторы устройств могут быть конфиденциальными. Для публичных примеров используйте вымышленный дом.

Это переведённое краткое руководство. Полная документация и иллюстрированная инструкция пока на английском. Исправления переводов приветствуются.

## Проверка кнопок без команд

В установленном плане Home Assistant включите Dry run, чтобы нажимать кнопки без отправки команд. Блокируются выключатели, питание телевизоров, шторы и системные окна с управлением замками; состояния остаются реальными. Добавьте ?dry_run=1 к адресу плана и сохраните закладку для этого браузера. Изменения расположения объектов по-прежнему можно сохранять.
