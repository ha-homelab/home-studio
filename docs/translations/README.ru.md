# Home Studio — Быстрый старт

[Home Studio](https://ha-homelab.github.io/home-studio/planner/?lang=ru) · [Languages](README.md)

Нарисуйте свой дом в браузере. Учётная запись не нужна. Язык можно выбрать в верхней части редактора.

1. Добавьте комнаты, стены, двери и окна. В библиотеке 195 моделей. Выберите цветовую палитру, а для подходящих предметов — рисунок поверхности.
2. Экспортируйте JSON, чтобы сохранить редактируемую копию. Черновик хранится только в этом браузере. Смена языка не изменяет ваш план.

Скачайте и распакуйте полный набор инструментов. Установите Python 3.10 или новее. В папке набора выполните:

[ZIP](https://github.com/ha-homelab/home-studio/archive/refs/heads/main.zip)

```sh
python3 scripts/build-planner-project.py --project /path/to/project.json --output dist/my-home --ha-package
```

Следуйте инструкции по установке на английском: в ней описаны резервные копии, Home Assistant OS, путь к конфигурации и перезапуск. Сам браузерный редактор не подключается к Home Assistant и не управляет устройствами.

[Home Assistant](https://ha-homelab.github.io/home-studio/install.html?lang=ru) · [README](../../README.md) · [i18n](../i18n.md)

План дома и идентификаторы устройств могут быть конфиденциальными. Для публичных примеров используйте вымышленный дом.

Это переведённое краткое руководство. Полная документация и иллюстрированная инструкция пока на английском. Исправления переводов приветствуются.

## Проверка кнопок без команд

В установленном плане Home Assistant включите Dry run, чтобы нажимать кнопки без отправки команд. Блокируются выключатели, питание телевизоров, шторы и системные окна с управлением замками; состояния остаются реальными. Добавьте ?dry_run=1 к адресу плана и сохраните закладку для этого браузера. Изменения расположения объектов по-прежнему можно сохранять.
