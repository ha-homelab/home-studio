# Home Studio — Швидкий початок

[Home Studio](https://ha-homelab.github.io/home-studio/planner/?lang=uk) · [Languages](README.md)

Намалюйте свій дім у браузері. Обліковий запис не потрібен. Мову можна вибрати у верхній частині редактора.

1. Додайте кімнати, стіни, двері та вікна. Бібліотека містить 195 моделей. Виберіть колірну палітру, а для сумісних предметів — візерунок поверхні.
2. Експортуйте JSON, щоб зберегти редаговану копію. Чернетка зберігається лише в цьому браузері. Зміна мови не змінює план.

Завантажте й розпакуйте повний набір інструментів. Установіть Python 3.10 або новішу версію. У папці набору виконайте:

[ZIP](https://github.com/ha-homelab/home-studio/archive/refs/heads/main.zip)

```sh
python3 scripts/build-planner-project.py --project /path/to/project.json --output dist/my-home --ha-package
```

Дотримуйтеся інструкції з установлення англійською: вона пояснює резервні копії, Home Assistant OS, шлях до конфігурації та перезапуск. Сам браузерний редактор не підключається до Home Assistant і не керує пристроями.

[Home Assistant](https://ha-homelab.github.io/home-studio/install.html) · [README](../../README.md) · [i18n](../i18n.md)

План дому та ідентифікатори пристроїв можуть бути конфіденційними. Для публічних прикладів використовуйте вигаданий дім.
