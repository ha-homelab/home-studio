## Почніть у Home Assistant

Для нового дому використовуйте Home Studio всередині Home Assistant. Окреме встановлення Python, YAML і токен доступу не потрібні.

Для наявного згенерованого або зміненого компонента спочатку прочитайте розділ **Existing generated homes** у докладному посібнику: автоматичного перетворення немає.

1. Установіть Home Assistant 2026.10 або новіший і зробіть резервну копію.
2. У HACS додайте `https://github.com/ha-homelab/home-studio` як власний репозиторій категорії **Integration**. Установіть стабільний випуск Home Studio з файлом **home_floorplan.zip** і перезапустіть Home Assistant.
3. Відкрийте **Settings → Devices & services → Add integration → Home Studio**.
4. Увійдіть як адміністратор і відкрийте **Home Studio** на бічній панелі. Намалюйте кімнату та прив’яжіть предмети до реальних пристроїв HA.
5. Натисніть **Save draft**, потім **Publish family view**. Відкрийте **3D Home** і перевірте прив’язки в **Dry run** перед керуванням пристроями.

[Home Assistant guide — English](../home-assistant-editor.md) · [Install — English](https://ha-homelab.github.io/home-studio/install.html#native-studio)

## Додатково: малювання, поки ви налаштовуєте HA

Окремий браузерний редактор можна використовувати, поки HA ще не готовий. Він не має живого підключення до HA. Експортуйте JSON, потім відкрийте його через **Open JSON** у Home Studio всередині HA, перевірте пристрої, збережіть та опублікуйте.

[Browser editor](https://ha-homelab.github.io/home-studio/planner/?lang=uk)

Намалюйте свій дім у браузері. Обліковий запис не потрібен. Мову можна вибрати у верхній частині редактора.

1. Додайте кімнати, стіни, двері та вікна. Бібліотека містить 206 моделей. Виберіть колірну палітру, а для сумісних предметів — візерунок поверхні.
2. Експортуйте JSON, щоб зберегти редаговану копію. Чернетка зберігається лише в цьому браузері. Зміна мови не змінює план.

### Додатково: переносний набір і компілятор Python

Цей шлях потрібен лише для окремого збирання та попередніх згенерованих установок; для нового вбудованого встановлення пропустіть його.

Завантажте й розпакуйте повний набір інструментів. Установіть Python 3.10 або новішу версію. У папці набору виконайте:

[ZIP](https://github.com/ha-homelab/home-studio/releases/latest)

```sh
python3 scripts/build-planner-project.py --project /path/to/project.json --output dist/my-home --ha-package
```

Дотримуйтеся інструкції з установлення англійською: вона пояснює резервні копії, Home Assistant OS, шлях до конфігурації та перезапуск. Сам браузерний редактор не підключається до Home Assistant і не керує пристроями.

[Home Assistant](https://ha-homelab.github.io/home-studio/install.html?lang=uk) · [README](../../README.md) · [i18n](../i18n.md)

План дому та ідентифікатори пристроїв можуть бути конфіденційними. Для публічних прикладів використовуйте вигаданий дім.

Це перекладений короткий посібник. Повна документація та ілюстрована інструкція поки англійською. Виправлення перекладів вітаються.

## Перевірка кнопок без команд

В установленому плані Home Assistant увімкніть Dry run для перевірки кнопок без надсилання команд. Вимикачі, живлення телевізорів, штори та системні вікна керування замками блокуються; стани залишаються справжніми. Збережіть адресу плану з ?dry_run=1 у закладці цього браузера. Зміни розташування об’єктів усе ще можна зберігати.
