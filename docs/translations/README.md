These localized README quick starts explain how to draw, save, compile and install a plan. Each links to the editor with its language selected. The full technical reference, illustrated tutorial and installed Home Assistant viewer currently remain in English. See [translation scope and contributions](../i18n.md).

Translations are maintained in the repository; no drawing or text is sent to an online translation service. Native-speaker improvements are welcome.
