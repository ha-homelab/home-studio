# Quality evidence and limitations

The package workflow tests real archive parsing, installation, backup/rollback,
public packaging, geometry and browser behavior. RC mutation campaigns target
production project validation and geometry; ordinary CI replays synthetic
regression corpora. Read [fuzzing](fuzzing.md) for exact scope and budgets.
[Security](../SECURITY.md) describes the reviewed import/archive trust boundary.
No whole-project function-coverage percentage or independent maintenance
continuity is claimed.

The primary maintainer confirms knowledge of secure design and common Python
and network-application vulnerabilities. The maintainer also confirms no bug,
enhancement or vulnerability reports outside GitHub in the preceding 12 months.
These are human attestations. Public issue history and current diagnostics must
also be checked when updating the OpenSSF assessment.
