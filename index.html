01 · INSTALL

Add Home Studio.

In HACS, add ha-homelab/home-studio as a custom Integration repository and download the stable version. Restart HA, then choose Settings → Devices & services → Add integration → Home Studio.

Follow the installation steps →

02 · DRAW

Make your first room.

Open Home Studio in the HA sidebar. Draw walls, doors, and windows, add furniture, and select your HA devices. The illustrated guide walks through the drawing tools.

Learn the drawing tools →

03 · PUBLISH

Bring the plan to life.

Choose Save draft, then Publish to 3D Home. Open 3D Home and check your bindings with Dry run. Later edits need no reinstall or restart.

Publish your first room →

NEW IN THE 1.1 BETA LINE

Your drawing, ready for Blender.

Refine furniture placement inside Home Assistant, then choose Export for Blender. Download one floor or the whole home as GLB or an OBJ + materials ZIP. GLB keeps furniture parts grouped so you can move each complete item.

Watch the three-step animated guide ↗Read the Blender guide →

Static geometry and material colors only; no device controls or credentials. Keep your drawing JSON: Blender changes do not currently import back into Home Studio.

OPTIONAL HELP WHILE YOU SET UP HOME ASSISTANT

Keep drawing if setup gets stuck.

Start with the HA setup troubleshooting steps. If you need to keep working while you resolve installation, use the separate browser editor below. It needs no account and does not connect to or control Home Assistant.

Choose Export JSON to keep your drawing. When Home Studio is ready in HA, use Open JSON, check your devices, then Save draft → Publish to 3D Home. A link between editors never transfers your home automatically.
