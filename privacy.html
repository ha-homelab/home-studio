Your design
and your data.

Home Studio saves your drawing and published view to your own Home Assistant through its authenticated connection. The optional separate editor needs no account and has no project upload service. Optional AI drafting has a separate, explicit data flow.

The editor inside Home Assistant

The native integration stores saved projects and published plans in your Home Assistant configuration data. These files can contain your layout, room and area identifiers, and device bindings. They belong in your private HA backups. They are not uploaded to the public website.

The trusted HA host sends a bounded device catalog and your drawing to a sandboxed editor. The editor never receives your HA access token. Save and Publish are administrator actions; the server checks permissions again. A per-tab recovery draft uses session storage in the HA host, separate from the public editor's local storage. Close the tab and remove site data when clearing shared computers.

Following a link between the native and separate editors transfers no project automatically. Export JSON and open it in the other editor when you intentionally want to move a design. Family accounts can view authorized floors and control permitted entities without permission to edit the project.

The separate browser editor

Your rooms, measurements, notes and optional device IDs are saved in this browser's local storage. Opening a JSON file reads it locally. Exporting downloads a file to your computer; it does not publish your home.

Use Export JSON before clearing browser data, switching browsers or using a private browsing window. Autosave is a convenience, not a backup. Someone using the same browser profile can see its saved draft.

Draft recovery can also retain one earlier project checkpoint and a copy of damaged saved data in the same browser storage. Replacing the current drawing does not erase these recovery copies. Clear this site's browser data to remove them all, after exporting anything you want to keep.

What the hosting service receives

GitHub Pages serves the website and its static files. Like other web hosts, GitHub receives requests for those files and logs visitor IP addresses for security. See GitHub's Pages data collection notice. The editor adds no analytics, advertising scripts, tracking pixels or cloud project synchronization.

Browser storage has boundaries

Local storage belongs to the website origin, not a GitHub repository or a person. Sites under the same ha-homelab.github.io origin share that browser storage boundary. A different browser, local address or domain has a separate draft. Export and reopen your file when moving between them.

Optional AI drafting

Plan from photos runs through your native HA integration or an optional local companion, not this shared website. API credentials stay in user-bound HA process memory, or in the companion's page-session memory, for at most 30 minutes. They are not saved in your project, browser storage or server configuration. The field is masked and cleared after connecting. End session clears the key; integration unload or process shutdown clears its sessions. Use HTTPS for a remote browser connection to HA. The operating system may still manage process memory or crash dumps.

Choosing Generate sends your instructions, prepared photos and relevant room context to the selected provider, together with the credential needed to authenticate. A cloud gateway receives the request before forwarding it to a model host. Provider billing, logging and retention policies still apply; “session-only” does not mean “never transmitted”. There is no Home studio cloud relay or analytics.

For local inference, requests go only to the loopback runtime you select, relative to the HA host/container or the companion computer. Whether that runtime itself calls a cloud service depends on its configuration. Disable its cloud features for a local-only workflow. Photos are resized and re-encoded before generation, but visible faces, documents and possessions remain visible. Review them before sending.

Generated output is treated as an untrusted draft. It cannot run code, request URLs, use your Home Assistant credentials or operate devices. Only an explicit Apply changes the drawing. AI credentials, source photos and raw provider responses are not part of your Home Assistant export.

Keep private details private

Do not put passwords, access tokens or camera URLs in notes or device fields. If you share a project file or screenshot, review its room layout, notes and device IDs first. Do not attach a real home design to a public GitHub issue.
