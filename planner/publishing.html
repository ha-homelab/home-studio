01 · THE RECOMMENDED WORKFLOW

Save and publish inside Home Assistant

  1. Use Home Assistant 2026.10 or newer. In HACS, add https://github.com/ha-homelab/home-studio as a custom repository with category Integration, then download a release containing home_floorplan.zip.
  2. Restart Home Assistant. Open Settings → Devices & services → Add integration and choose Home Studio.
  3. Open Home Studio in the sidebar as an administrator. Choose Add your first room and enter its dimensions. You can add furniture and device links later.
  4. Choose Save draft and wait for confirmation. When the drawing is ready, choose Publish to 3D Home.
  5. Wait for publication to finish, then choose Open 3D Home. Enable Dry run to check any device bindings before turning on live controls.
Save draft
Keeps the editable project in Home Assistant. It can contain unfinished floors and does not update the published geometry.
Publish to 3D Home
Validates and builds the saved drawing into 3D Home. Each floor needs a valid room. A failed publication keeps the previous home available.
More options → Export drawing (JSON)
Downloads an additional editable backup. It is not required for native publication and does not publish a website.

Publishing does not operate devices. Everyday family use happens in 3D Home or a dashboard card; source editing and publication require an administrator.

Existing generated homes: back up Home Assistant and retain your source JSON before changing installation routes. Customized components and private adapters are not automatically migrated or preserved by the generic integration. Read the installation and migration guidance first.

02 · KEEP AN EDITABLE COPY

Save your draft and keep a JSON backup

  1. In Home Studio, choose Save draft and wait for confirmation, then More options → Export drawing (JSON). Your browser downloads project.json.
  2. Move the file from Downloads to a folder you will remember. Rename it to describe the version, such as my-home-first-draft.json.
  3. To check the backup, choose Open JSON and select that file. Confirm that the rooms and items look right in Plan 2D and Preview 3D.

The file stores the editable project: floors, room shapes, walls, openings, items and any entity IDs you entered. Exporting does not create a separate website, a 3D model download or a Home Assistant package.

Wait for Save draft: Home Assistant stores the confirmed native draft. A tab recovery copy helps with interrupted editing but is not a backup. Keep Home Assistant backups and exported JSON versions before large changes or opening a different project. If another tab changes the project, export the version you want before reloading.

Where your drawing lives

In the native workflow, the saved draft and published assets stay in your Home Assistant private data, outside the integration code. They do not go to the hosted editor. An exported JSON copy contains the drawing and entity bindings you entered.

The optional hosted editor keeps a separate draft in its browser profile; it does not upload or sync the project to HA. Browser storage belongs to the website origin, which other pages on the same origin share. GitHub serves that static website and logs visitor IP addresses for security; see GitHub's hosting notice. Do not enter passwords or tokens in your project.

03 · LET SOMEONE OPEN THEIR OWN COPY

Share the drawing file

Send your exported JSON file to someone you choose. They can select Open JSON in their own Home Studio editor and explore their own editable copy. Their edits do not change your draft; they can export a new version to send back.

For everyday use by family accounts on your Home Assistant, publish the family view and use 3D Home; a JSON transfer is unnecessary. Sending a website link does not grant access to your saved home. JSON exchange creates independent copies, not live collaboration.

Before sharing a file, review its room names, item notes and entity IDs. An exported project contains the details you entered. Keep a private backup of the original.

Optional fallback: keep drawing in the separate editor

If Home Assistant setup has problems, use the hosted editor while you troubleshoot. It needs no installation and has no HA connection. Its browser draft is local to the browser and website address, so keep a copy with Export JSON.

When HA is ready, use Open JSON in its Home Studio sidebar, check the imported drawing, then Save draft and Publish to 3D Home. Neither editor automatically transfers or overwrites the other's project.

Optional: use the portable toolkit

Use the downloaded toolkit's editor offline

For offline drawing, download home-studio-VERSION.zip from the release assets, extract it and keep its folders together. From the extracted toolkit folder, run:

python3 -m http.server 8099 --bind 127.0.0.1

Open http://127.0.0.1:8099/planner/ and keep the terminal running while you draw. Double-clicking index.html is not supported.

Use Export JSON and Open JSON to move your drawing between the hosted and local copies; their browser storage is separate. The toolkit also includes the compiler and installer; run those separately in your terminal when you follow the portable installation reference. The portable route creates a generated integration and uses its documented YAML and local file steps; those steps are not part of a new native installation.
